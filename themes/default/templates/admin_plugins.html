Plugins

Browse the plugin directory and install plugins with one click. Directory plugins are dynamic: they can add settings and head/footer HTML. Plugins that add pages or background jobs ship compiled into goblog.

Installing plugins needs ENABLE_DYNAMIC_PLUGINS=true and a writable, persisted plugins/dynamic/ directory (bind-mount it with Docker). See the README under Dynamic plugins. You can still browse the directory.
— directory URL is set under Settings → plugin_directory_url.
Plugins run as Go code inside goblog with the same access it has. Install only plugins from sources you trust.
