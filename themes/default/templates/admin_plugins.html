Plugins

Browse the plugin directory and install plugins with one click. Directory plugins run sandboxed in WebAssembly and can add pages, background jobs, settings and head/footer HTML. They can only reach the hosts they declare.

WebAssembly plugins are disabled (ENABLE_WASM_PLUGINS=false). Remove that setting (WASM is on by default) to install plugins from the directory. You can still browse it.
— directory URL is set under Settings → plugin_directory_url.
Directory plugins run sandboxed in WebAssembly, with network access limited to the hosts they declare. Built-in and legacy Go plugins run as ordinary code inside goblog with the same access it has. Plugins add HTML to every page (head/footer hooks) and own their pages; install only plugins you trust.
